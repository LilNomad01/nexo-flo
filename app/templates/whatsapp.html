Baileys • não oficial

Conectar Baileys na Vercel

O Nexo Flow gera o QR pela própria Vercel e persiste as chaves da sessão cifradas no PostgreSQL. Não é necessário manter o terminal ligado.

Atenção: Baileys não é uma API oficial do WhatsApp. A conexão é reaberta sob demanda para QR, validação e envio.

Oficial

Conectar Meta Cloud API

Onde encontro os dados oficiais?
  1. Abra o Meta for Developers e selecione seu aplicativo.
  2. Entre em WhatsApp → API Setup.
  3. Copie o access token, o Phone Number ID e o WhatsApp Business Account ID.
  4. Em produção, prefira um token de System User com as permissões necessárias.

Atenção: a UAZAPI é uma integração não oficial. O uso pode sofrer desconexões ou restrições do WhatsApp.
